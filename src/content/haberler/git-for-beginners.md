Git is a version control system that records changes to your files over time.

## Commit

A commit is a snapshot of the project at that moment. Writing a meaningful message for each commit keeps the history readable.

## Branch

A branch lets you try a new feature without breaking the main work. When it is ready, it is merged back into the main branch.

## Merge

The changes of two branches are combined with a merge. If the same lines conflict, you decide by hand.
